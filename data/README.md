# Data setup

This project uses the **Brazilian E-Commerce Public Dataset by Olist**. Raw CSV files are excluded from the repository to keep the portfolio lightweight and avoid redistributing third-party data.

Download the dataset from its original public listing:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Place the extracted CSV files in this folder. The expected filenames include:

- `olist_customers_dataset.csv`
- `olist_geolocation_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_order_payments_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_orders_dataset.csv`
- `olist_products_dataset.csv`
- `olist_sellers_dataset.csv`
- `product_category_name_translation.csv`

Power Query currently contains local source paths. Update the source paths in Power BI Desktop after downloading the files on another computer.
